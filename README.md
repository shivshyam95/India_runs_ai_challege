# The AI Recruiting Brain: Semantic Candidate Ranking Engine

This project was built for The Data & AI Challenge as part of the India.Runs event. It features an AI-powered system designed to match candidate resumes to job descriptions with high accuracy.

## How it Works
1. Stage 1 (Filtering): Uses AI embeddings to instantly find the top matching candidates from the dataset.
2. Stage 2 (Re-ranking): Uses a deep learning model to score candidates on a 0-100% scale based on their skills and experience.

## Tech Stack
* Language: Python
* Frameworks: Sentence-Transformers, Pandas, Scikit-learn
